# School, College and University Management Platforms: Research, Rankings and Open-Source Blueprint

Research by Manus AI, November 2026 (evidence checked 24–27 November 2026). The repository contains:

- a ranked **top 20 worldwide** and a separate **top 10 India** list of school, college and university management platforms (SIS, MIS, school ERP, campus ERP);
- a complete dossier for each platform, plus 10 more evaluated candidates;
- a backend teardown of the top 3 system-of-record platforms;
- the **OpenCampus One** blueprint for a new open-source "one platform for all".

Every link in every document is a full, visible URL.

## Ranking Method in Brief

Each platform is scored 0–10 on five dimensions:

| Dimension | Weight |
|---|---:|
| Feature breadth | 30% |
| Adoption (most used) | 30% |
| Advanced features | 20% |
| UX and mobile | 10% |
| Interoperability | 10% |

Global and Indian lists are ranked separately with the deterministic script in 07-methodology-and-skill. The full rubric is at https://github.com/S4syedRauf/school-management-platforms-research/blob/main/07-methodology-and-skill/edtech-platform-research/references/scoring-rubric.md

## Accuracy Notes

- Adoption figures are mostly vendor claims and are labelled with dates in each dossier.
- Most enterprise vendors publish no prices. Third-party figures are labelled as estimates.
- Prices, ownership and market share change. Re-check the official URLs in each dossier before purchasing.
- The backend teardown uses only lawful public evidence: documentation, public GitHub repositories, NVD, breach notices and passive REA observation of public pages.

## How to Rebuild the Master Report

```bash
python3 08-scripts/build_results.py        # builds results_global.json / results_india.json from profiles and scores
python3 07-methodology-and-skill/edtech-platform-research/scripts/rank_platforms.py results_global.json --out rank_global_all.md --json rank_global_all.json
python3 08-scripts/assemble_report.py      # assembles the master report
python3 07-methodology-and-skill/edtech-platform-research/scripts/lint_links.py 01-report/School_Management_Platforms_Report.md
```

The scripts were written for the original research workspace layout. Adjust the BASE path at the top of each script to run them from this repository.
